Daily Games

One puzzle a day, same for everyone, done in a few minutes. A hand-picked list of Wordle-style games that go beyond words: maps, music, movies, logic, prices, history and more.

Tick a game when you've played it; ticks reset each day and are saved only in this browser. Links point to independent sites, and daily games come and go, so the occasional link may break. The list is maintained in the GitHub repo; suggestions welcome.
