# Daily Games

A curated list of "one puzzle a day" games in the spirit of Wordle: everyone gets the same puzzle, it takes a few minutes, and you share your result. The focus is on games that **aren't** word games: geography, music, film, logic, perception, sports, prices, history and more.

> **About sources.** The goal was to mine Reddit (r/wordle, r/WebGames, r/puzzles and "what daily games do you play?" threads). Reddit blocks automated access from the research environment, so the list was built from community-curated lists that collect the same recommendations: the [adoryvo dailies list](https://adoryvo.github.io/lists/dailies.html), a [Tildes "games like Wordle" thread](https://tildes.net/~games/1coe/looking_for_games_like_wordle), [dles.gg](https://dles.gg/), [The Daily Games Hub](https://dailygames.xyz/), [greatest.games](https://greatest.games/blog/best-daily-puzzle-games), [Laura Michet's blog](https://blog.lauramichet.com/daily-web-games-i-am-currently-playing/) and press roundups (PC Gamer, NPR). The games in ⭐ are the ones that come up most often in these lists and in Reddit threads in general.
>
> Last compiled: November 2026. Links come from those lists; daily-game sites move or shut down often, so expect a few dead links.

## Start here: the big ones

If you only try ten, try these. They cover very different skills.

| Game | What you do |
|---|---|
| ⭐ [Worldle](https://worldle.teuteuf.fr) | Name a country from its silhouette, using distance and direction hints. |
| ⭐ [Travle](https://imois.in/games/travle) | Connect two countries by naming the countries along the shortest land route. |
| ⭐ [Framed](https://framed.wtf) | Guess a movie from up to six stills. |
| ⭐ [Bandle](https://bandle.app) | Guess a song as instruments are added one by one. |
| ⭐ [Clues by Sam](https://cluesbysam.com) | Mark a grid of people as criminal or innocent using chained clues. |
| ⭐ [Costcodle](https://costcodle.com) | Guess the price of a Costco item with higher/lower hints. |
| ⭐ [TimeGuessr](https://timeguessr.com) | Guess where and when a photo was taken. |
| ⭐ [Metazooa](https://metazooa.com) | Find the mystery animal; each guess shows the closest shared branch of the tree of life. |
| ⭐ [Nerdle](https://nerdlegame.com) | Wordle, but the answer is a valid math equation. |
| ⭐ [Immaculate Grid](https://www.immaculategrid.com) | Fill a 3×3 grid with players matching each row and column (baseball, plus other sports). |

## Bonus: the word-adjacent classics

Not the focus here, but they appear in almost every Reddit list:

- [Connections (NYT)](https://www.nytimes.com/games/connections): sort 16 items into four hidden groups.
- [Strands (NYT)](https://www.nytimes.com/games/strands): themed word search with a spangram.
- [Raddle](https://raddle.quest): riddle-driven word ladder.
- [Redactle](https://redactle.net): uncover a redacted Wikipedia article.
- [Semantle](https://semantle.com): guess a word by meaning, not spelling.
- [Squaredle](https://squaredle.app): Boggle-style daily grid.
- [Waffle](https://wafflegame.net/daily): swap letters to fix a waffle-shaped grid.
- [Minute Cryptic](https://www.minutecryptic.com): one cryptic crossword clue a day.
